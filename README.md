# Лабораторная работа №1 — отчёт

**Задача:** описательная статистика и проверка гипотез по клиентской базе страховой MedGuard (датасет Medical Cost Personal Dataset, 1 338 клиентов).

## Что в папке

```
lab/
├── lab_1.ipynb      ← готовая лабораторная: код, графики, выводы, выполнены все ячейки
├── insurance.csv    ← данные (скачаны из репозитория задания)
└── .venv/           ← виртуальное окружение Python (pandas, scipy, seaborn)
```

## Как открыть

- Ноутбук открывается в Jupyter / VS Code.
- Для воспроизведения расчётов: ядро Python из `.venv` (`.venv/bin/python -m ipykernel install --user` при необходимости), дальше Run All.

## Ввод

Выгрузка по 1 338 застрахованным: возраст, пол, BMI, дети, курение, регион, годовые выплаты. Пропусков нет. Требовалось описать базу и проверить «общеизвестные» цифры компании статистически (α = 0,05, z-критерий и доверительные интервалы).

## Результаты

- «Курильщик = 30 000» — отклонено (32 050, p = 0,003); «средний клиент 39 лет» — верно (p = 0,590); «northeast = 12 500» — не опровергнуто, точечно +7%; «southeast > 13 000» — подтверждено (14 735, p = 0,009); бонус: средний BMI > 30 (p ≈ 3,5·10⁻⁵).
- 95% ДИ средней выплаты 12 356–17 362 USD; ДИ курильщиков [30 684; 33 417] и некурящих [8 074; 8 794] не пересекаются.
- 139 дорогих клиентов (10% базы) = 33% всех выплат — закономерный сегмент «курильщик + высокий BMI», не аномалии.

## Личный вывод

1. **Среднее само по себе лжёт, если не смотреть на форму распределения.** По скошенным выплатам среднее (13 270) на 41% выше медианы (9 382) — одна «красивая цифра на слайд» без гистограммы и медианы вводит в заблуждение.
2. **Выброс — не всегда мусор.** Автоматическое правило 1,5·IQR отметило 139 человек, но это не ошибки данных, а осмысленный сегмент (97,8% — курильщики). Первый шаг при виде выброса — понять, кто это, и только потом решать, удалять ли.
3. **Одна выборка — не аргумент.** Пять выборок по 100 дали средние от 11 930 до 14 859 USD. Теперь любую точечную оценку с выборки я сопровождаю доверительным интервалом: он показывает цену маленькой выборки.
4. **ЦПТ — это рабочий инструмент, а не абстракция.** Даже у сильно скошенных выплат средние 1000 выборок сложились в нормальный колокол, и эмпирическая se совпала с теоретической — поэтому z-тесты и ДИ здесь применимы.
5. **«Не отклонили H₀» ≠ «H₀ верна».** Для northeast бюджет формально «прошёл» (p = 0,147), но точечная оценка на 7% выше бюджета. Гипотеза проверяет только противоречие данным, а риски для бизнеса надо оценивать отдельно.
6. **Дизайн выборки решает:** стратификация по региону не помогла (регион почти не влияет на выплаты), а по `smoker` — критична, потому что именно курение двигает деньги.

Практически для PM: тарифы — по сегментам `smoker` × `region`, индивидуальная оценка андеррайтинга — для BMI ≳ 41.
